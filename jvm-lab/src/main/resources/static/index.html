触发场景

红框按钮会真的把对应资源打爆 —— 都在容器内，有 cgroup 硬限制兜底，不会影响宿主。
鼠标停在按钮上可以看这个场景对应的核心代码（ⓘ 标记）。
堆 OOM 之后所有请求都会失败（堆满了），点右上角「复位」即可恢复。
死锁无法靠复位解除，需要 ./lab.sh restart。
GC 空转需要先 ./lab.sh restart gc-overhead 换 profile 才可能触发报错， 当前默认 G1 下只会一直空转不报错。
