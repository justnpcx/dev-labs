按难度分四级，建议从初级顺着往上走。

开始之前，先做这三件事：
  1. 用 Chrome 打开，按 F12 打开 DevTools
  2. 切到 Network 面板，勾上 Disable cache（否则缓存类场景看不出来）
  3. 每次测完按 Ctrl+Shift+R 硬刷新，保证数据干净
页面右上角都有「看优化版 →」按钮，可以直接在问题版和优化版之间跳转。 页面标题下方的彩色徽章就是它的难度级别。
