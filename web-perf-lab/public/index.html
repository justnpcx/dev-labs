前端性能演练场

14 个场景，每个都有 问题版 和 优化版 两个独立页面。 开两个标签页并排对比，在 Chrome DevTools 的 Network / Performance 面板里看差别。

开始之前，先做这三件事：
  1. 用 Chrome 打开，按 F12 打开 DevTools
  2. 切到 Network 面板，勾上 Disable cache（否则缓存场景看不出来）
  3. 每次测完按 Ctrl+Shift+R 硬刷新，保证数据干净
提示：页面右上角都有「看优化版 →」按钮，可以直接在问题版和优化版之间跳转。
