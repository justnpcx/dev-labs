用 left / top 做动画

看优化版 →

DevTools 观察清单

  1. 先打开 Rendering 面板（Ctrl+Shift+P → 输入 "Rendering"）
  2. 勾上 Paint flashing（绿框闪烁 = 重绘了）
  3. 再勾上 Layer borders（橙色边框 = 独立合成层）
  4. 点「开始动画」—— 注意方块全程都在闪绿框，而且没有橙色边框
  5. 打开 Performance 面板录制，看 Main 轨道上每帧都有 Layout + Paint
  6. 去优化版做同样的操作对比
预期：每一帧都触发 Layout → Paint → Composite
Performance 里 Main 轨道被紫色(Layout)和绿色(Paint)填满
为什么 left/top 这么贵
浏览器渲染一帧分几步： 
JS → Style → Layout → Paint → Composite
left / top 是布局属性 —— 改它意味着这个元素的位置变了，Layout 必须重算。 如果它旁边还有别的元素（可能被挤动），Layout 的范围还会扩大。

而 transform 是合成属性 —— 它只影响这个元素自己的绘制结果，不改变布局， 浏览器可以直接交给 GPU 在合成阶段处理，连重绘都不需要。

演示

点一下开始，注意 Paint flashing 的绿框 
等待开始…

问题代码

function tick() {
  const t = (Date.now() % 2000) / 2000;
  const x = t * 400;

  mover.style.left = x + 'px';    // ❌ 布局属性 → 每帧重算 Layout
  mover.style.top  = (Math.sin(t * 6) * 10) + 'px';   // ❌ 再来一次

  requestAnimationFrame(tick);
}

哪些属性会触发什么

属性触发开销
width, height,
padding, margin,
left, top, font-size		 Layout + Paint + Composite 最高
color, background,
box-shadow, border-radius		 Paint + Composite 中
transform, opacity,
filter		 Composite 最低

记法：能让元素"看起来变了但位置尺寸没变"的属性， 通常都能走合成。
