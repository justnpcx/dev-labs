动态 JS 替换

不改服务器代码，在浏览器里改线上 JS

练习步骤

  1. 打开 Sources 面板 → 左侧切到 Overrides 标签
  2. 点 Select folder for overrides，选一个本地空文件夹，授权
  3. 回到 Page 标签，展开 localhost:8082 → assets → 找到 override-demo.js
  4. 双击打开，找到 discountRate: 0.1 这一行
  5. 改成 discountRate: 0.25
  6. 按 Ctrl+S 保存 —— 文件名旁边会出现一个紫色圆点
  7. 回到这个页面按 Ctrl+Shift+R 硬刷新
  8. 价格应该变成 ¥150，而且服务器上的文件一个字节都没动
验证：改完后用 curl 看服务端文件，应该还是 0.1： 
curl -s localhost:8082/assets/override-demo.js | grep discountRate
为什么要用这个
· 线上出 bug 时，直接改服务器代码风险大、要走发布流程
· 用 Overrides 可以在本地浏览器里验证修复方案，确认有效再提交
· 也能拿来临时改接口返回、改样式、绕过前端校验做调试

注意：Overrides 只影响你自己的浏览器， 对真实用户和其他同事没有任何影响。

CSS 调样式不用改代码重新部署，调好了再抄回去

几个容易卡住的点

① 改了没生效？
检查三件事：文件旁边有没有紫色圆点（没保存）→ 有没有硬刷新（Ctrl+Shift+R，普通刷新可能用缓存）→ Overrides 文件夹是不是被取消了授权。

② 找不到文件？
必须在 Page 标签下按域名展开，不是 Filesystem。 有些内联在 HTML 里的脚本没有独立文件，改不了。

③ 想取消覆盖？
在 Overrides 面板里右键文件 → Delete， 或者把文件夹整个移除。

和「改完再抄回源码」配合使用
标准流程是：
1. 在 Overrides 里试，确认方案有效
2. 把改动抄回本地源码
3. 走正常的提交 / 发布流程
不要在 Overrides 里"改好了"就以为问题解决了 —— 那只是你自己的浏览器。
