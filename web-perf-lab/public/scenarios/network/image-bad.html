DevTools 观察清单

  1. Network 面板，勾上 Disable cache，硬刷新
  2. 找到那张 PNG，看它的 Size —— 应该是 360 KB 左右
  3. 看 Priority 列 —— 首屏大图应该标 High，下面那张懒加载的是 Low
  4. 切到 Performance 面板，勾上 Web Vitals（右上角齿轮 → 或者用 Lighthouse）
  5. 录制一次页面加载，看 Experience 轨道上有没有 Layout Shift 标记（紫色）
  6. 看 LCP 标记落在哪个元素上
预期：图片 360 KB（随机噪声压不动）
页面加载时下方文字会往下跳 —— 这就是 CLS。
为什么会跳（CLS）
<img> 没写 width/height 时， 浏览器一开始不知道它要占多大地方，只能先按 0 高度布局。 图片下载完才撑开 —— 后面的内容被整体推下去。
这就是 CLS（Cumulative Layout Shift，累积布局偏移）， 是 Core Web Vitals 三大指标之一。

<img src="/api/image?w=800&h=600"
     width="800" height="600"        ← 预留空间，CLS = 0
     loading="lazy"                  ← 首屏外延后加载
     fetchpriority="high"            ← 告诉浏览器这是 LCP 元素
     alt="...">
