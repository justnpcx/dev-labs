三种引入方式的区别

写法下载执行时机阻塞解析
<script> 立即下载完立刻执行 是
<script defer> 并行HTML 解析完后，按顺序 否
<script async> 并行下载完立刻，顺序不定 否

怎么选

defer：脚本之间有依赖、或者要操作 DOM 时用。
async：完全独立的脚本（统计埋点、广告），谁先下完谁先跑。
都不加：基本没有正当理由 —— 除非你就是要它先于页面执行 （比如必须在渲染前设置主题色，防止闪白）。

现代做法：用 type="module"，它默认就是 defer。

还能更进一步

defer 只是"不挡解析"。要让首屏更快，还可以：

手段作用
rel="preload"提前下载关键资源，提高优先级

SSR / 流式渲染不等 JS 就有内容
