首屏内容在 1.5 秒后才出现，用户看到的是白屏。
为什么 head 里的同步 script 这么致命
HTML 解析是单线程的。解析器碰到 <script>（没有 defer/async）时：
  1. 暂停解析
  2. 下载脚本（网络耗时）
  3. 执行脚本（CPU 耗时）
  4. 才继续解析后面的 HTML
第 2、3 步期间，页面是白的 —— 因为后面的 HTML 还没被解析出来。

这个脚本里做了什么

const deadline = Date.now() + 1500;
let x = 0;
while (Date.now() < deadline) {   // 忙等，占满主线程
  x += Math.sqrt(x + 1);
}
window.__LAB_BLOCK_RESULT = x;    // 防止被 JIT 优化掉

真实世界里阻塞源通常是：同步的 XHR、巨大的 JS bundle 解析执行、 同步的 localStorage 读写、复杂的模板编译。
