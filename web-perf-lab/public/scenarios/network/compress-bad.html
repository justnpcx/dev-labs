服务端做了什么（或者说没做什么）

问题版故意不设置 Content-Encoding， 把 300KB 文本原样发出去： 

// 响应头里只有这些，没有 Content-Encoding
Content-Type: text/javascript; charset=utf-8
Content-Length: 307319

// 优化版会多一行：
Content-Encoding: gzip

为什么收益这么大

JS / CSS / HTML / JSON 都是文本，有大量重复的模式（变量名、 关键字、缩进、重复的字符串）。gzip 就是找重复并替换成短引用， 通常能压到 1/5 ~ 1/10。

反过来，已经压缩过的格式（JPEG、PNG、WebP、MP4、ZIP） 再 gzip 几乎没有收益 —— 它们内部已经没多少冗余了。
