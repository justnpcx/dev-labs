DevTools 观察清单

  1. 打开 Network，先不要勾 Disable cache
  2. 点「请求 3 次」——同一个 URL 连发 3 次
  3. 看 3 条记录的 Status：都是 200 还是有的 304？
  4. 看 Size 列：每次都传了完整字节吗？
  5. 点开任意一条 → Headers → 看 Response Headers 里的 Cache-Control
预期：3 次全是 200，每次都传完整 body
因为响应头写了 Cache-Control: no-store —— 浏览器不允许把它存进缓存。
no-store 和 no-cache 不是一回事（名字太像了）：
· no-store —— 完全不存，下次必然重新下载
· no-cache —— 可以存，但每次都要向服务器确认（拿到 304 就用本地的）
问题版用的是 no-store，所以连确认的机会都没有。
